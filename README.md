# USAF-DATA-ANALYSIS
Este pequeño proyecto de POWER BI lo hice como un pequeño hobbie para poder representar un poco mis gustos por los aviones de la USAF//Navy de USA

El proyecto en Power BI muestra 2 perspectivas, una en cada hoja, que representa estadisticamente cuantos aviones hay por generacion, por proposito y tambien donde se ubican alrededor del mundo
