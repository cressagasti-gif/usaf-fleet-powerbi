## EN

A personal project built to explore the United States Air Force fleet through
Power BI — how many aircraft exist per **generation**, what **mission** each one
performs, and **where** they are based around the world.

### What it contains

| Report page | Contents |
|---|---|
| Report 1 | Fleet size by aircraft generation |
| Report 2 | Fleet breakdown by mission type and worldwide location |

### How to open

The deliverable is a `.pbix` file, so it needs Power BI Desktop (Windows).

1. Download [`USAF PROYECT.pbix`](USAF%20PROYECT.pbix)
2. Open it in **Power BI Desktop**
3. Interact with the report pages

> GitHub cannot render `.pbix` files in the browser — they are binary project
> packages, not images. You have to open them locally to see the visuals.

### What I learned

- Modelling fleet data so multiple visuals could share one consistent structure
- Choosing the right visual for counts, categories and geography
- Keeping a report readable by splitting it into focused pages instead of
  cramming everything onto one canvas

## ES

Proyecto personal para explorar la flota de la Fuerza Aérea de los Estados
Unidos con Power BI: cuántos aviones hay por **generación**, qué **misión**
cumple cada uno y **dónde** están ubicados en el mundo.

### Qué contiene

| Página | Contenido |
|---|---|
| Reporte 1 | Cantidad de aviones por generación |
| Reporte 2 | Desglose por tipo de misión y ubicación mundial |

### Cómo abrirlo

El entregable es un archivo `.pbix`, así que necesita **Power BI Desktop** (Windows).

1. Descargá [`USAF PROYECT.pbix`](USAF%20PROYECT.pbix)
2. Abrilo con **Power BI Desktop**
3. Interactuá con las páginas del reporte

> GitHub no puede mostrar archivos `.pbix` en el navegador: son paquetes de
> proyecto binarios, no imágenes. Hay que abrirlos localmente para ver los
> gráficos.

### Qué aprendí

- Modelar datos de flota para que varios visuales compartieran una estructura
  consistente
- Elegir el visual correcto para conteos, categorías y geografía
- Mantener un reporte legible separándolo en páginas enfocadas en vez de
  meter todo en un mismo lienzo
